# White Network Monitor v2.0 (WPF Edition)

Красивое нативное приложение на **C# WPF** в тёмно-фиолетовых тонах:
градиенты, скруглённые карточки, тени, свечение статуса.
Запускается на любой Windows 10/11 **без установки** .NET (target net472).

## Запуск готового exe

```
bin\Release\net472\WhiteNetMonitor.exe
```

При старте появляется только иконка в трее (WT + Wi-Fi + бейдж).
ЛКМ по иконке — открыть монитор, ПКМ — меню.

## Что внутри

| Экран | Данные |
|---|---|
| 🌐 Сеть | Статус-пилюля со свечением (Онлайн/Нет сети), локальный IP, реальные скорости ↓↑ из счётчиков интерфейсов, пинг до 8.8.8.8 |
| 📊 Система | CPU / RAM / Диск C: с градиентными прогрессбарами, ОС, время работы |

- Проверка интернета: TCP к 8.8.8.8:53 каждые 5 сек (без нагрузки на CPU)
- Скорости: дельта байтов всех активных адаптеров раз в секунду
- Пинг: System.Net.NetworkInformation.Ping, только по кнопке
- CPU%: kernel32.GetSystemTimes; RAM: GlobalMemoryStatusEx — без PerformanceCounter'ов
- Иконка трея рисуется кодом (GDI+): градиентный круг, «WT», Wi-Fi-арки,
  зелёная галочка / красный крест; перерисовка только при смене статуса

## Интерфейс

- Окно без рамки, скруглённые углы, фиолетовое свечение вокруг
- Диагональный градиент фона #170B29 → #3A1A63, карточки-«стёклышки»
- Сегментный переключатель вкладок с градиентной заливкой
- Крестик/сворачивание скрывают окно в трей (выход — через меню иконки)
- Чекбокс «Запускать с Windows» — пишет себя в HKCU\...\Run
- Одиночный экземпляр приложения (второй запуск просто завершается)

## Сборка

```
dotnet build -c Release
```

Готовый файл появится в `bin\Release\net472\WhiteNetMonitor.exe`.
